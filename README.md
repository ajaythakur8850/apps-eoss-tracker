# Apps Winter EOSS Tracker – Jharkhand

Daily sell-thru tracker for Apps Winter EOSS stock (qty level) across Jharkhand stores.

- `index.html` – the portal (GitHub Pages). Sign in with E-Code + EOSS PIN (first PIN 1234, separate from Leave Planner).
- `stock.enc` – EOSS opening stock (26 Nov 2026), encrypted; unlocked only after sign-in.
- Sale data is uploaded from the 0ANALYSIS sale report and stored in the separate "EOSS Tracker" Google Sheet via its own Apps Script backend (apps-script/Code.gs).
