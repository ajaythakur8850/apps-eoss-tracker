# Apps Winter EOSS Tracker – Jharkhand

Daily sell-thru tracker for Apps Winter EOSS stock (qty level) across Jharkhand stores.

- `index.html` – the portal (GitHub Pages). Sign in with E-Code + PIN (same as Leave Planner).
- `stock.enc` – EOSS opening stock (26 Nov 2026), encrypted; unlocked only after sign-in.
- Sale data is uploaded from the 0ANALYSIS sale report and stored in the Leave Planner Google Sheet (EOSS_Sales, EOSS_Uploads).
